# Wemakeover-app

Monorepo for Wemakeover:

| Folder | What |
|--------|------|
| `wemakeover-rn/` | Mobile app (Expo / React Native) |
| `client/` | Web admin + marketing site (Vite / React) |
| `server/` | API (Express + Neon PostgreSQL + Prisma) |

## Quick start

See each folder’s README / `.env.example` for setup.

- API: `server/` → `npm run dev`
- Web: `client/` → `npm run dev`
- App: `wemakeover-rn/` → `npm run start`
